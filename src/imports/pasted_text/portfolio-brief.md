## Visual hierarchy

I want dramatic differences in scale.

For example:

* very large project titles
* small metadata
* oversized imagery
* lots of breathing room

Do not make everything the same size.

I like layouts that feel intentionally asymmetric while still being highly structured.

Use a grid underneath the design, but do not make the grid visually obvious.

The site should feel designed rather than templated.

## Typography

Typography is extremely important.

Use a neutral modern sans-serif as the foundation.

I want some combination of:

* oversized editorial headings
* compact technical labels
* very readable body copy

Use ALL CAPS sparingly for metadata and navigation.

Avoid making the entire site uppercase.

Keep paragraphs narrow enough to read comfortably.

## Interaction

Add subtle interaction where appropriate.

Examples:

* project image slightly shifts or scales on hover
* project title reacts gently to hover
* thin rules animate
* cursor feedback
* subtle image reveal
* restrained text transitions

Interaction should feel precise and tactile.

Nothing should bounce.

Nothing should move enough that text becomes difficult to read.

No scroll hijacking.

* scale
* composition
* motion

before adding decoration.

* spacing
* typography

* section heights
* alignment
* borders

without breaking the site.

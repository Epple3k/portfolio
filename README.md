# Emit Rice — Portfolio

**Website:** [emitrice.com](https://emitrice.com/)

This is the source code for the personal portfolio of **Emit Rice**, an information systems student and human-centered AI research assistant at Florida State University. The site showcases projects in product design, human-computer interaction, data visualization, and creative technology.

## Selected work

- [Attention Field](https://emitrice.com/projects/attention-field/) — Wikipedia data visualization
- [Research Atlas](https://emitrice.com/projects/research-atlas/) — interdisciplinary research discovery interface
- [Aural Field](https://emitrice.com/projects/aural-field/) — generative ambient audio
- [Ledgerline](https://emitrice.com/projects/ledgerline/) — financial research and AI interface
- [2030canvas](https://emitrice.com/projects/2030canvas/) — participatory planning research instrument and prototype case study

## Development

React, TypeScript, Vite, and Tailwind CSS. The build generates crawlable project case-study pages and a sitemap through `scripts/generate-seo-pages.mjs`.

The live site and its project pages are the canonical public presentation of this work.

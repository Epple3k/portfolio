WHAT IT IS

Financial research without severing the answer from the evidence.

Ledgerline is an MCP connector concept and working prototype for public-company research. The connector normalizes SEC filings, XBRL facts, filing text, dilution signals, peer comparisons, and macro series into a small tool surface that ChatGPT can reason over.

The visual interface explores a complementary HCI question: what if every AI-generated financial explanation carried an inspectable provenance graph by default?

The public demo uses illustrative values for interaction design. The MCP source included with the project retrieves live primary-source data.

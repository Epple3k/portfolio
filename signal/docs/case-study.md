# SIGNAL: financial relationships as an investigable environment

The product hypothesis is that stable spatial context and time-based exploration can help people follow financial relationships, while inspectable records prevent visual confidence from replacing analytical evidence.

The workspace prioritizes a single network over metric cards. Three modes share the same case, timestamp, and selection: Observe establishes context; Investigate exposes records and features; Experiment changes actual pipeline inputs. Progressive disclosure keeps detailed metadata in the inspector and methodology page.

The technical work integrates an integer-cent ledger, reproducible simulation, isolated evaluation labels, fitted anomaly models, transparent temporal rules, asynchronous API jobs, and multiple synchronized presentations. The most important safeguard is that the backend owns computation, and the browser owns presentation.

Evaluation deliberately includes failures: the hub's central account is found while many peripheral injected accounts do not enter the review queue. Some ordinary accounts rank as anomalies. Those are visible limitations, not findings to hide.

The next research step is a comparative study of 3D, 2D, and table investigations, measuring task accuracy, completion time, evidence comprehension, navigation cost, and confidence calibration. No usability improvement is asserted before such a study.
